## 🛠️ 面板凭证与命令维护

如果忘记面板密码或安全入口，可通过 SSH 登录服务器后使用 `1pctl` 工具快速查询或重置：

```bash
# 1. 查看面板完整登录信息（入口、用户名等）
ssh super***@106.****.251 "sudo 1pctl user-info"

# 2. 重置面板登录密码
ssh super***@106.****.251 "sudo 1pctl update password"

# 3. 查看 1Panel 服务运行状态
ssh super***@106.****.251 "sudo 1pctl status"
```
